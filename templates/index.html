Welcome to my week 2 project

Python web application

This weeks project uses MariaDB, Python, Nginx and HTML. MariaDB is used as a database for traffic counting on the page. It works through Python, which fetches and writes the data. That data is then passed to the HTML template. Nginx catches requests from users to pass them right back to the application,

Traffic counter

Webpage loaded: {{ kaynnit }}

The traffic counter works as a python application that stores the count permanently in the database. Everytime the webpage is opened, it will execute a Python script and writes the updated value to MariaDB. That is why the value wont reset even if application server restarts.

Restart Test result

When Gunicorn was restarted, the counter data remained fully intact because it is loaded dynamically from MariaDB. Nginx rerouted the traffic to the new process fast, and neither Nginx nor MariaDB needed to be restarted.
